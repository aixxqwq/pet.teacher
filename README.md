# Bilim Buddy — учись вместе с питомцем

*Білім* по-казахски — «знание», *buddy* — «друг». Bilim Buddy — друг, с которым учиться интереснее.

Учебный сайт-тамагочи. Питомец сыт, когда ты отвечаешь на вопросы, и растёт, когда ты занимаешься
с фокус-таймером.

🌐 **Открыть сайт:** https://bilim-buddy.onrender.com

## Что внутри

- 🐾 **Питомец-учитель.** Овечка, капибара, хомяк, панда, утёнок или ёжик. Питомец радуется,
  когда ты учишься, и грустит, если давно не заходила.
- ✦ **ИИ-учитель.** Чат с твоим питомцем на базе DeepSeek. Объясняет тему простыми словами,
  разбирает вопрос, на котором ты ошиблась (кнопка «Спросить учителя» прямо в задании),
  видит твой прогресс и советует, что повторить. Говорит по-русски, но не решает за тебя,
  а наводит на ответ.
- 🎓 **Мини-подготовка к IELTS.**
  - *Speaking:* Part 1 (15 тем), Part 2 (16 карточек cue card: минута на подготовку и до двух минут речи по таймеру)
    и вопросы Part 3. Ответ можно записать на микрофон и переслушать.
  - *Writing:* Task 2 (20 эссе), Task 1 (6 графиков и диаграмм, 5 писем). Есть таймер
    и счётчик слов.
  - *Проверка ИИ:* учитель ставит примерный band по четырём критериям IELTS (Task Response,
    Coherence, Lexical Resource, Grammar) и показывает, что исправить.
- 📚 **Около 560 вопросов:** английский A1–C1, математика (с графиками и геометрией),
  физика, химия, биология, история, история Казахстана, география, Python.
  Уровень растёт только за новые вопросы, а ошибки попадают в «Работу над ошибками».
- 🃏 **Карточки с интервальным повторением.** Тот же метод, что в Anki.
- ⏱ **Фокус-таймер.** Помодоро, во время которого питомец тоже «занимается».
- 👤 **Аккаунты.** Прогресс сохраняется на сервере, и войти можно с любого устройства.

Без сервера сайт тоже работает прямо в браузере, но тогда без аккаунтов и ИИ-учителя.

## Как открыть

Дважды кликни по `index.html`, и сайт откроется в браузере.

Можно запустить и как настоящий сайт на своём компьютере:

```
python -m http.server 8000
```

После этого открой в браузере http://localhost:8000.

## Сервер: аккаунты и ИИ-учитель

Без сервера сайт тоже работает, прогресс хранится в браузере. Чтобы включить **аккаунты**
и **ИИ-учителя**, запусти сайт через сервер на Python (FastAPI + база SQLite):

1. Дважды кликни `run.bat`. Он установит пакеты, запустит сервер и откроет http://localhost:8000.
2. Открой `server/.env` в блокноте и впиши ключ DeepSeek: `DEEPSEEK_API_KEY=...`.
   Ключ создаётся на platform.deepseek.com → API keys. Файл `.env` не попадает в GitHub.
3. Перезапусти `run.bat`.

Что умеет сервер (`server/`):

| Файл | Что внутри |
|---|---|
| `main.py` | адреса API: регистрация, вход, прогресс, чат с учителем, проверка эссе |
| `db.py` | база SQLite `server/data/pet_teacher.db`: пользователи, сессии, прогресс |
| `tutor.py` | запросы к DeepSeek и инструкции для учителя |

- **Пароли** хранятся только в виде хэша (PBKDF2), сам пароль на сервере не лежит.
- **Прогресс** синхронизируется автоматически каждые 10 секунд. На другом компьютере достаточно войти.
- **ИИ-учитель** видит сводку твоего прогресса: секции, ошибки, карточки, фокус, IELTS.
  Он отвечает на вопросы, объясняет ошибки (кнопка «Спросить учителя» после неверного ответа),
  составляет план и проверяет эссе IELTS по 4 критериям.
- **Лимит:** 60 вопросов учителю в день на ученика, чтобы не потратить весь баланс.
  Меняется настройкой `AI_DAILY_LIMIT` в `.env`.

## Сайт в интернете (Render + Neon)

Сайт запускается на бесплатном хостинге **Render**, а аккаунты хранятся в бесплатной облачной
базе **PostgreSQL** на **Neon**. Отдельная база нужна потому, что бесплатный хостинг стирает
свои файлы при каждом перезапуске.

1. **База:** neon.tech → войти через GitHub → Create project → скопировать *Connection string*
   (начинается с `postgresql://`).
2. **Хостинг:** render.com → войти через GitHub → **New → Blueprint** → выбрать репозиторий.
   Render прочитает `render.yaml` и попросит три значения:
   - `DEEPSEEK_API_KEY` — ключ DeepSeek;
   - `DATABASE_URL` — строка из Neon;
   - `ADMIN_USERS` — твой логин на сайте.
3. Через 2–5 минут сайт откроется по адресу вида `https://bilim-buddy.onrender.com`.
4. Обновить сайт: отправь изменения в GitHub, Render обновит его сам.
   Выключить сайт: в Render → Settings → *Suspend* или *Delete*.

На бесплатном Render сайт «засыпает» через 15 минут без посетителей. Первое открытие после
этого занимает около минуты, дальше всё работает быстро.

## Карточки с интервальным повторением

Карточка — это вопрос на лицевой стороне и ответ на обратной. Вспомни ответ, переверни карточку
и честно оцени себя: «Не помню», «Трудно», «Помню» или «Легко». От оценки зависит,
когда карточка вернётся: через минуту, через день, через 3 дня, через неделю, через месяц…
Каждый раз интервал растёт, поэтому знания переходят в долгую память, а повторять
приходится совсем немного. Логика лежит в `js/cards.js`, это упрощённый алгоритм SM-2, как в Anki.

## Прогресс по секциям

Секция — это тема и уровень, например «История · Лёгкий». Опыт дают **только за вопросы,
решённые впервые**. Когда все вопросы секции решены, сайт предлагает перейти на уровень выше.
Повторять секцию можно, но питомец за повторы опыта не получает. Решённые вопросы хранятся
в поле `solved` у питомца.

Вопросы собираются скриптом `tools/build_questions.py` из файлов `tools/bank_stem.py` и
`tools/bank_hum.py`. Графики и фигуры к задачам рисует `tools/figures.py` (SVG).

## Работа над ошибками

Если ответить неверно, вопрос сам попадает в тему **«Работа над ошибками»**. Она появляется первой
в списке тем. Когда ответишь на такой вопрос правильно, он оттуда исчезнет.

## Дизайн

Светлый фон с медленно плывущими цветными пятнами, стеклянные полупрозрачные карточки
(`backdrop-filter: blur`) и тёмные блоки с «северным сиянием» из нескольких градиентов.

## Питомцы

Шесть питомцев в стиле стикеров: овечка, капибара, хомяк, панда, утёнок и ёжик.
Все нарисованы кодом в формате SVG (файл `js/pets.js`), поэтому картинки не нужны.

У каждого питомца своя поза и анимация на каждое действие:

| Когда | Что делает питомец |
|---|---|
| ждёт | дышит, моргает, наклоняет голову |
| учится | читает книжку в очках, страницы переворачиваются |
| верный ответ | ест печенье, вокруг сердечки |
| ошибка | грустит, катится слеза |
| перерыв | слушает музыку в наушниках, вокруг летят ноты |
| отдых | спит в колпаке на подушке, вокруг Zzz |
| фокус-таймер | печатает на ноутбуке |
| перерыв в таймере | пьёт бабл-ти |
| новый уровень | надевает корону, вокруг блёстки |

## Правила

| Действие | Что происходит |
|---|---|
| Верный ответ | +3 сытости и опыт: от +10 до +30 XP, чем сложнее уровень, тем больше |
| 5 верных подряд | бонус +10 XP и +2 настроения |
| Ошибка | серия сбрасывается, −1 настроение |
| Перерыв | +3 настроения, −2 энергии, −1 сытость |
| Отдых | +4 энергии |
| Сессия фокуса | опыт за каждую минуту: 25 минут дают +20 XP |

Каждые 30 XP дают новый уровень. Стадии питомца: новичок → ученик → эксперт → мастер.

Пока сайт закрыт, время идёт: каждые 2 часа сытость и настроение уменьшаются на 1.

**Не отвлекайся.** Если во время фокуса переключиться на другую вкладку, питомец это заметит,
загрустит и запишет отвлечение в статистику дня.

## Что такое JSON и где здесь сохранение

**JSON** — это способ записать данные текстом так, чтобы их легко прочитали и человек, и программа.
Питомец в игре — это объект, почти как словарь в Python:

```json
{
  "name": "Зефирка",
  "animal": "panda",
  "food": 7,
  "fun": 5,
  "energy": 8,
  "xp": 47
}
```

Браузер умеет хранить текст в **localStorage**. Это маленькое хранилище для каждого сайта,
и данные в нём не пропадают после закрытия вкладки. Объект превращается в текст и обратно так:

```js
// сохранить: объект → JSON-текст → хранилище
localStorage.setItem("petTeacher.pet", JSON.stringify(pet));

// загрузить: хранилище → JSON-текст → объект
const pet = JSON.parse(localStorage.getItem("petTeacher.pet"));
```

То же самое в Python делают `json.dump` и `json.load`.

На главной странице есть кнопка **«Скачать .json»**. Она сохраняет питомца, твои вопросы и
статистику в обычный файл, который можно открыть в блокноте. Кнопка **«Загрузить»** возвращает
всё обратно.

## Как добавить вопрос в код

Открой `js/questions.js` и допиши строку в массив:

```js
{"topic": "Английский", "level": "A2", "question": "Как по-английски «кошка»?", "answer": "cat", "wrong": ["dog", "cow", "car"]},
```

- `topic`: тема. Если написать новую, она сама появится на сайте.
- `level`: уровень из списка темы.
- `wrong`: неверные варианты. Если оставить `[]`, ответ нужно будет напечатать.

Без кода вопросы можно добавить на странице **«Мои вопросы»**.
