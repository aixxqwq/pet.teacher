# 🦄 Питомец-учитель

Тамагочи, который ест знания. Чтобы покормить питомца, нужно правильно ответить на вопрос:
по Python, английскому, математике или просто на «умный» вопрос. Питомец запоминается
в файл `save.json` и ждёт тебя, даже если закрыть игру.

## Как запустить

Нужен только Python 3 (`tkinter` уже встроен, ничего ставить не надо):

```
python main.py
```

| 🦄 | Единорог | радужное яблоко |
| 🐑 | Овечка | клевер |
| 🐉 | Дракончик | огненный перчик |
| 🪱 | Червяк | сочный листик |
| 🐧 | Пингвин | рыбка |
| 🐼 | Панда | бамбук |

## Правила

- **📚 Учиться и покормить**: вопрос с 4 вариантами. Верно → +3 сытости и +10 опыта.
  Неверно → серия сбрасывается, настроение −1, игра показывает правильный ответ.
- **5 верных подряд**: бонус +10 опыта и +2 настроения.
- **🎾 Поиграть**: +3 настроения, но −2 энергии и −1 сытость.
- **😴 Спать**: +4 энергии.
- **Время идёт по-настоящему**: каждые 2 часа (даже когда игра закрыта) сытость и настроение
  падают на 1, а энергия восстанавливается на 1.
- **Уровни**: каждые 30 опыта дают новый уровень. Стадии: малыш → подросток → взрослый → мудрец.

## Что такое JSON

**JSON** — это способ записать данные в обычный текстовый файл так, чтобы их легко было
прочитать и человеку, и программе. Он очень похож на словари и списки Python.

Питомец в игре — это словарь, такой же, как в твоём первом `program.py`:

```python
pet = {"name": "Пуся", "animal": "dragon", "food": 5, "fun": 5}
```

А вот как он выглядит в файле `save.json`:

```json
{
  "name": "Пуся",
  "animal": "dragon",
  "food": 5,
  "fun": 5
}
```

Почти одно и то же! Отличия JSON от Python:
- строки только в **двойных** кавычках `"..."`;
- `true` / `false` / `null` вместо `True` / `False` / `None`;
- после последнего элемента не ставится запятая.

### Как сохранить (Python → файл)

```python
import json

with open("save.json", "w", encoding="utf-8") as f:      # "w" = write, открыть на запись
    json.dump(pet, f, ensure_ascii=False, indent=2)     # dump = "выгрузить" словарь в файл
```

- `encoding="utf-8"` — чтобы русские буквы и эмодзи сохранились правильно;
- `ensure_ascii=False` — писать «Пуся», а не `Пуся`;
- `indent=2` — красивые отступы, чтобы файл было удобно читать глазами.

### Как загрузить (файл → Python)

```python
with open("save.json", "r", encoding="utf-8") as f:      # "r" = read, открыть на чтение
    pet = json.load(f)                                  # load = "загрузить" обратно в словарь

print(pet["name"])   # Пуся
```

Если файла ещё нет, `open` выдаст ошибку, поэтому в `pet.py` мы сначала проверяем
`os.path.exists(...)`, а сломанный файл ловим через `try / except json.JSONDecodeError`.

Ещё есть `json.dumps(...)` / `json.loads(...)` (с буквой **s** = string): они делают то же самое,
но со строкой, а не с файлом.

## Как добавить свой вопрос

Открой `questions.json` и добавь блок (не забудь запятую между блоками):

```json
{
  "category": "Английский",
  "question": "Как по-английски «кошка»?",
  "answers": ["cat", "dog", "cow", "car"],
  "correct": 0
}
```

`correct` — номер правильного ответа, **считая с нуля** (как индексы в списках Python).
Игра сама перемешивает варианты. Если написать новую `category`, в меню появится новая тема.
